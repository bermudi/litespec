# litespec

A lean, AI-native spec-driven development CLI written in Go.

litespec keeps your codebase aligned with durable, load-bearing specs. One GitHub issue is the queue. Three lean skills guide AI agents from a fuzzy idea to a verified, demo-able unit.

---

## What makes litespec different

**GitHub issue is the queue.** Proposal + design + implementation queue live in the issue body with `Base:` and `Branch:` ownership metadata. `plan[clear]` starts clean and creates a dedicated branch. When `gh` is unavailable, `specs/queues/<name>.md` is the equivalent local queue.

**Two lanes.** Small fix: zero ceremony, edit code and the one `specs/<feature>/spec.md` directly. New feature: plan fuzzy → clear → grill-me → build one unit at a time → review → close the issue.

**Three generated skills.** `litespec-plan`, `litespec-build`, and `litespec-review` live in `.agents/skills/` (`.claude/skills/` symlinks for Claude Code). Generated by `litespec update`.

**Direct spec edits.** `specs/<feature>/spec.md` is the durable contract: SHALL/MUST body text, WHEN/THEN scenarios. Edit it in place. No staging, no reconciliation.

---

## Quick start

```bash
# Install
go install github.com/bermudi/litespec/v2/cmd/litespec@latest

# Set up a project
litespec init
litespec init --tools claude   # optional Claude Code symlinks
```

Six commands: `init`, `validate`, `view`, `update`, `upgrade`, `completion`.
