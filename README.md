# litespec

A lean, AI-native spec-driven development CLI.

`go 1.26.1+` · [Full docs → https://bermudi.github.io/litespec/](https://bermudi.github.io/litespec/) · Inspired by [OpenSpec](https://github.com/Fission-AI/OpenSpec)

litespec gives AI coding agents a durable contract to work against and a lean way to prove the work happened. Small fixes need no ceremony. Bigger work goes through a GitHub issue that holds the plan plus one verifiable unit at a time.

```bash
go install github.com/bermudi/litespec/v2/cmd/litespec@latest
litespec init
```

Read the docs to start: [Getting Started](https://bermudi.github.io/litespec/getting-started/) → [Tutorial](https://bermudi.github.io/litespec/tutorial/) → [CLI Reference](https://bermudi.github.io/litespec/cli-reference/).
